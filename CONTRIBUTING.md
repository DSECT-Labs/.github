# Contributing to DSECT Labs

## Workflow

1. Create a branch from the default branch.
2. Keep changes scoped to one concern.
3. Open a pull request with a short why + what.
4. Do not force-push shared default branches.

## Repositories

- Default new product work to **private** until it is ready to publish.
- Put reusable templates and org files in this `.github` repo.
- Tag repos with the org custom properties (`project`, `stack`) once those are enabled.

## Reviews

Solo work can merge after self-check. When a second person is on the team, require at least one review on default branches.
